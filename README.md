# 📊 Imersão Dados com Python

Este repositório contém o material completo de uma série de 4 aulas focadas no domínio da biblioteca **Pandas** para Ciência de Dados. Ao longo do projeto, exploramos um dataset real de salários na área de tecnologia para extrair insights valiosos.



---

## 📑 Conteúdo das Aulas

### 🔹 Aula 1: Fundamentos e Exploração
* Configuração do ambiente e importação do **Pandas**.
* Leitura de dados remotos (CSV).
* Métodos de exploração: `df.head()`, `df.info()` e `df.describe()`.
* Entendendo a estrutura de DataFrames e Series.

### 🔹 Aula 2: Limpeza e Filtragem (Em desenvolvimento)
* Identificação e tratamento de dados ausentes.
* Filtragem de dados por condições (ex: salários > 100k).
* Seleção de colunas específicas e manipulação de índices.

### 🔹 Aula 3: Agrupamentos e Transformações (Em desenvolvimento)
* Uso do `groupby` para comparar médias salariais por cargo.
* Criação de novas colunas e transformação de variáveis categóricas.
* Ordenação de dados para rankings.

### 🔹 Aula 4: Visualização e Relatório Final (Em desenvolvimento)
* Criação de gráficos integrados ao Pandas.
* Análise visual de tendências (trabalho remoto vs. presencial).
* Conclusões baseadas nos dados explorados.

* **Python 3.x**
* **Pandas** (Análise de dados)
* **Google Colab** (Ambiente de desenvolvimento)
